# vervos

Practicá tus verbos rioplatenses: a phone-first app for practising Rioplatense Spanish (voseo) verb conjugations.

## What's here

- `index.html` is the whole app: one self-contained file with all CSS, JS and data (202 verbs, every sentence batch). Open it in a browser to run it.
- `tools/conj.py` is the voseo conjugation engine, used to auto-check each sentence's answer.
- `tools/verbs.py` holds the verb list and metadata.
- `docs/NOTES.md` has design and code notes: data format, tabs, header, theme, songs.
